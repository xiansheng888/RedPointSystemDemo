# RedPointSystemDemo 红点系统使用指南

## 一、系统架构概述

红点系统是一个**树形层级结构**的通知系统，采用**观察者模式**实现红点数量变化的自动通知。系统架构如下：

```
RedPointSystem (单例管理器)
    ├── RedPointNode (树形节点)
    │   ├── nodeName: 节点名称
    │   ├── pointNum: 红点数量
    │   ├── parent: 父节点引用
    │   ├── dicChilds: 子节点字典
    │   └── numChangeFunc: 数量变化回调事件
    │
    └── RedPointConst (常量定义)
```

## 二、现有节点结构

系统已定义的节点层级（在 `RedPointConst.cs` 中）：
```
Main (根节点)
├── Mail (邮件)
│   ├── System (系统邮件)
│   ├── Team (队伍邮件)
│   └── Alliance (联盟邮件)
├── Task (任务)
└── Alliance (联盟)
```

## 三、核心API接口

### 1. 初始化系统
```csharp
// 在游戏启动时调用一次（通常在BootStart.cs中）
RedPointSystem.Instance.InitRedPointTreeNode();
```

### 2. 设置红点数量
```csharp
// 触发红点更新（Model层使用）
// rpNum: 正数表示增加红点，0表示清除红点，负数表示减少红点
RedPointSystem.Instance.SetInvoke("Main.Mail.System", 1);  // 增加1个红点
RedPointSystem.Instance.SetInvoke("Main.Mail.System", 0);  // 清除红点
```

### 3. 查询红点状态
```csharp
// 主动查询当前红点状态（View层初始化时使用）
RedPointNode node;
if (RedPointSystem.Instance.GetNodeRedPoint("Main.Mail.System", out node))
{
    // node.pointNum > 0 表示有红点
    // node.pointNum 表示具体数量
}
```

### 4. 注册红点变化回调
```csharp
// 注册回调监听红点变化（推荐方式）
RedPointSystem.Instance.SetRedPointNodeCallBack("Main.Mail.System", (node) =>
{
    // node.pointNum 获取当前红点数量
    // 在此更新UI显示状态
});
```

## 四、在UI功能中使用红点系统

```csharp
static List<string> lstRedPointTreeList = new List<string>
```

#### 步骤3：在业务逻辑中触发红点
```csharp

public void MarkItemAsViewed(ItemData item)
```

#### 步骤4：在UI中显示红点
```csharp
public class ShopView : MonoBehaviour
{
    public GameObject shopButton;          // 商店主按钮
    public GameObject newItemIndicator;    // 新商品提示
    
    private void Awake()
    {
        // 方式1：主动查询初始化显示
        RedPointNode node;
        if (RedPointSystem.Instance.GetNodeRedPoint(RedPointConst.shop, out node))
        {
            shopButton.transform.Find("redPoint").gameObject.SetActive(node.pointNum > 0);
            shopButton.transform.Find("redPoint/Text").GetComponent<Text>().text = node.pointNum.ToString();
        }
    }
    
    private void OnEnable()
    {
        // 方式2：注册回调监听变化（推荐）
        RedPointSystem.Instance.SetRedPointNodeCallBack(RedPointConst.shop, OnShopRedPointChanged);
        RedPointSystem.Instance.SetRedPointNodeCallBack(RedPointConst.shopNewItem, OnNewItemRedPointChanged);
    }
    
    private void OnShopRedPointChanged(RedPointNode node)
    {
        // 更新商店按钮红点
        bool hasRedPoint = node.pointNum > 0;
        shopButton.transform.Find("redPoint").gameObject.SetActive(hasRedPoint);
        if (hasRedPoint)
        {
            shopButton.transform.Find("redPoint/Text").GetComponent<Text>().text = node.pointNum.ToString();
        }
    }
    
    private void OnNewItemRedPointChanged(RedPointNode node)
    {
        // 更新新商品提示
        newItemIndicator.SetActive(node.pointNum > 0);
    }
    
    private void OnDisable()
    {
        // 可选：取消注册回调
        // 系统会自动管理，但显式取消可以避免内存泄漏
    }
}
```

### 场景2：使用现有红点系统（邮件系统示例）

#### 邮件Model层（触发红点）
```csharp
public class MailModel
{
    // 收到新邮件时
    public void AddMail(MailData mail)
    {
        mails.Add(mail);
        
        // 根据邮件类型触发对应红点
        switch (mail.mailType)
        {
            case MailType.System:
                RedPointSystem.Instance.SetInvoke(RedPointConst.mailSystem, 1);
                break;
            case MailType.Team:
                RedPointSystem.Instance.SetInvoke(RedPointConst.mailTeam, 1);
                break;
            case MailType.Alliance:
                RedPointSystem.Instance.SetInvoke(RedPointConst.mailAlliance, 1);
                break;
        }
    }
    
    // 阅读邮件时
    public void MarkMailAsRead(MailData mail)
    {
        mail.isRead = true;
        
        // 清除对应红点
        switch (mail.mailType)
        {
            case MailType.System:
                RedPointSystem.Instance.SetInvoke(RedPointConst.mailSystem, 0);
                break;
            case MailType.Team:
                RedPointSystem.Instance.SetInvoke(RedPointConst.mailTeam, 0);
                break;
            case MailType.Alliance:
                RedPointSystem.Instance.SetInvoke(RedPointConst.mailAlliance, 0);
                break;
        }
    }
}
```

#### 邮件View层（显示红点）
```csharp
public class MailView : MonoBehaviour
{
    public GameObject systemMailBtn;
    public GameObject teamMailBtn;
    public GameObject allianceMailBtn;
    
    private void OnEnable()
    {
        // 注册所有邮件类型的红点回调
        RegisterRedPointCallbacks();
    }
    
    private void RegisterRedPointCallbacks()
    {
        // 系统邮件红点回调
        RedPointSystem.Instance.SetRedPointNodeCallBack(RedPointConst.mailSystem, (node) =>
        {
            UpdateRedPointUI(systemMailBtn, node.pointNum);
        });
        
        // 队伍邮件红点回调
        RedPointSystem.Instance.SetRedPointNodeCallBack(RedPointConst.mailTeam, (node) =>
        {
            UpdateRedPointUI(teamMailBtn, node.pointNum);
        });
        
        // 联盟邮件红点回调
        RedPointSystem.Instance.SetRedPointNodeCallBack(RedPointConst.mailAlliance, (node) =>
        {
            UpdateRedPointUI(allianceMailBtn, node.pointNum);
        });
    }
    
    private void UpdateRedPointUI(GameObject button, int pointNum)
    {
        Transform redPoint = button.transform.Find("redPoint");
        if (redPoint != null)
        {
            bool showRedPoint = pointNum > 0;
            redPoint.gameObject.SetActive(showRedPoint);
            
            if (showRedPoint)
            {
                Text text = redPoint.GetComponentInChildren<Text>();
                if (text != null)
                {
                    text.text = pointNum.ToString();
                }
            }
        }
    }
}
```

## 五、最佳实践

### 1. **何时使用主动查询 vs 回调监听**
- **主动查询 (`GetNodeRedPoint`)**: 
  - 适合初始化显示
  - 适合一次性检查
  - 在 `Awake()` 或 `Start()` 中使用
  
- **回调监听 (`SetRedPointNodeCallBack`)**:
  - 适合持续监听变化
  - 避免频繁查询
  - 在 `OnEnable()` 中注册，`OnDisable()` 中清理（可选）

### 2. **红点节点命名规范**
- 使用点分隔的层级结构：`"Parent.Child.GrandChild"`
- 根节点必须是 `"Main"`
- 在 `RedPointConst` 中定义常量，避免硬编码

### 3. **UI红点显示约定**
- 红点GameObject命名为 `"redPoint"`
- 红点数量文本放在 `"redPoint/Text"` 路径下
- 红点显示逻辑：`pointNum > 0` 时显示，否则隐藏

### 4. **Model层触发规则**
- 新增内容：`SetInvoke(nodePath, 1)`
- 清除红点：`SetInvoke(nodePath, 0)`
- 批量更新：`SetInvoke(nodePath, count)`（正数增加，负数减少）

### 5. **性能优化**
- 红点更新使用队列机制，避免频繁UI刷新
- 父节点自动汇总子节点数量，无需手动计算
- 使用异步更新，避免阻塞主线程

## 六、常见问题解答

### Q1: 如何添加新的红点类型？
1. 在 `RedPointConst.cs` 中定义节点常量
2. 在 `RedPointSystem.cs` 的 `lstRedPointTreeList` 中添加节点
3. 在业务逻辑中调用 `SetInvoke()`
4. 在UI中注册回调或查询状态

### Q2: 红点数量如何传递？
- 叶子节点变化时，自动向上传递到父节点
- 父节点的红点数量 = 所有子节点红点数量之和
- 例如：`mailSystem` 有红点 → `mail` 自动显示红点 → `Main` 自动显示红点

### Q3: 红点可以显示具体数量吗？
可以！系统支持显示具体数量：
```csharp
// 设置多个红点
RedPointSystem.Instance.SetInvoke("Main.Mail.System", 3);

// UI中显示数量
text.text = node.pointNum.ToString();  // 显示 "3"
```

### Q4: 如何测试红点系统？
```csharp
// 测试代码示例
void TestRedPointSystem()
{
    // 初始化系统
    RedPointSystem.Instance.InitRedPointTreeNode();
    
    // 触发红点
    RedPointSystem.Instance.SetInvoke(RedPointConst.mailSystem, 1);
    
    // 查询状态
    RedPointNode node;
    bool hasRedPoint = RedPointSystem.Instance.GetNodeRedPoint(RedPointConst.mail, out node);
    Debug.Log($"邮件有红点: {hasRedPoint}, 数量: {node?.pointNum}");
    
    // 清除红点
    RedPointSystem.Instance.SetInvoke(RedPointConst.mailSystem, 0);
}
```

## 七、扩展建议

### 1. **红点样式定制**
可以扩展系统支持不同样式的红点：
- 数字红点（默认）
- 小圆点红点（只显示点，不显示数字）
- 感叹号红点（重要提示）
- 自定义图标红点

### 2. **红点优先级**
可以添加优先级系统：
- 高优先级红点（红色）
- 中优先级红点（橙色）
- 低优先级红点（黄色）

### 3. **红点自动清理**
可以添加自动清理机制：
- 定时清理过期红点
- 根据业务规则自动清除
- 用户操作后批量清除
